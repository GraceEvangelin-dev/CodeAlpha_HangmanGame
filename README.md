# CodeAlpha Hangman Game

## Project Overview
This project is a simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

The player guesses a hidden word one letter at a time. The game ends when the player guesses the complete word or reaches the maximum number of incorrect guesses.

## Features
- Random selection from 5 predefined words
- Letter-by-letter guessing
- Maximum of 6 incorrect guesses
- Input validation
- Duplicate letter detection
- Win and lose conditions

## Technologies Used
- Python
- Random module

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   python hangman.py
